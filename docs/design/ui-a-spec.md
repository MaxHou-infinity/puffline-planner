# v3.5.0 界面方向 A：清爽专业

状态：所有者已确认视觉样稿；桌面实现与本机macOS验证完成，待所有者验收。
2026-10-19：所有者从A清爽专业/B工程工作台/C可视化建模中选择A。

## 设计依据

主任务是配置工序、识别瓶颈并比较产能/人力。保留工序列表、中央画布、
报警及底部运行控制的熟悉路径。通过表格排版、细分隔、控件高度与字号统一
改善视觉，不加入装饰渐变、大量阴影或营销式指标卡。

- 工作区 #F4F6F9，面板 #FFFFFF，正文 #202B3C，次级文字 #637084，边界 #E2E7EE。
- 操作蓝 #285DE5；警示色只用于异常标记，不给每道工序分配颜色。
- macOS中文用PingFang SC，Windows用Microsoft YaHei；正文14px，辅助12px，
  分区标题14px/600，数字使用等宽数字特性，指标24px/600。
- 按钮/输入框高36px，圆角6px，去除立体凸边；表格行高44px，不使用竖网格。
- 左侧列表用于选择与定位，中央节点显示节拍/人数/能力；右侧提醒保持白底。
- KPI在一条有分隔的统计栏中展示，避免等面积大卡片抢占画布。
- 编辑器按基本信息、加工能力、质量与换型分组；单位紧邻输入框，
  常用参数可直接看见，保存/取消固定在底部。

## 样稿与验证

样稿：`ui-a-preview.html`，离线可打开，无网络依赖。
覆盖工序选择、编辑弹窗、字段校验、保存/取消与运行状态预览；未连接仿真引擎。
默认指标由consumer-hardware-demo.json的模型公式计算，明确显示为示例预估，
参数编辑只用于预览控件反馈，不重算产能。

实测Python3.13/macOS；Python3.8和Windows实测仍待发布阶段执行。
