# PuffLine Planner 用户指南

PuffLine Planner 是面向电子烟制造场景的离散事件仿真与人力规划工具。本指南介绍安装、基础工作流、配置口径和常见问题；产品亮点与下载入口见[项目主页](../README.md)。

## 安装与启动

### 方式一：使用已打包应用（推荐）

前往 [GitHub Releases](https://github.com/MaxHou-infinity/puffline-planner/releases)，下载与操作系统对应的压缩包：

- 当前公开版本 v3.3.3 起：下载 `PuffLine-Planner-macOS-v<版本号>.zip` 或 `PuffLine-Planner-Windows-v<版本号>.zip`，解压后运行 `PuffLine Planner.app` 或 `PuffLine-Planner.exe`。
- 历史 v3.3.2：附件仍使用 `E-Pod-Line-Simulator-macOS-v3.3.2.zip` 或 `E-Pod-Line-Simulator-Windows-v3.3.2.zip`，解压后运行历史名称的 App 或 EXE。

已打包应用无需另行安装 Python 依赖。请以 Release 页面实际列出的附件为准。

macOS 首次打开时，如果 Gatekeeper 阻止启动，请在访达中右键应用并选择“打开”，或前往“系统设置 → 隐私与安全性”确认打开。当前应用尚未完成 Apple 签名与公证，请只从本项目官方 Release 页面下载。

### 方式二：从源码启动

源码运行需要 Python 3.8 或更高版本。克隆或下载仓库后执行：

```bash
cd e_pod_line_simulator
python -m pip install -r requirements.txt
python run.py
```

源码压缩包也提供便捷启动器：

- macOS：双击 `启动.command`
- Windows：双击 `启动.bat`

启动器会检查运行依赖；缺少依赖时，会在用户确认后联网安装。macOS 若提示无法打开 `启动.command`，请在访达中右键该文件并选择“打开”。

仓库的 `examples/` 目录提供两份脱敏的烟弹装配线方案，可用于熟悉方案导入和对比流程。

## 第一次完成仿真

首次启动时会自动打开快速配置向导；若已关闭，可随时通过
“文件 → 快速配置向导”再次打开。未配置工序时，画布上方会显示
“打开快速配置向导”入口，一键直达。

推荐从内置向导开始：

1. 选择“文件 → 快速配置向导”。
2. 选择生产类型和产线模板；也可以导入 Excel 配置。
3. 设置班次时长、休息时间与工人时薪。
4. 完成向导，并选择是否立即开始仿真。
5. 在主界面观察工序画布、KPI 仪表盘和报警信息。
6. 根据瓶颈与报警调整工序人数、节拍、OEE 或缓冲区，再次仿真验证。

也可以在左侧“工序配置”区域手动添加、编辑或删除工序。运行中会暂时锁定部分编辑操作，请先停止仿真再修改配置；暂停只冻结运行时间，不开放配置编辑。

## 从仿真到决策

### 识别瓶颈与失衡

- 画布会高亮瓶颈工序并展示物料流与 WIP 状态。
- KPI 仪表盘展示瓶颈产能、日产量、成本、平衡率和 UPPH 等指标。
- 报警区会提示瓶颈、资源浪费、WIP 堆积、饥饿或堵塞等情况。
- “分析”菜单提供敏感性试算、批量试算、智能优化与人力规划。

仿真结果用于方案预评估，不应替代现场测时、设备能力验证或质量验证。

### 保存与对比方案

1. 完成一版产线配置后，点击主界面的“保存方案”，或选择“文件 → 保存方案”。
2. 调整工序、人力或班次配置，再保存其他方案。
3. 选择“方案 → 方案管理 / 对比”。
4. 进入对比模式，勾选需要比较的方案并确认。
5. 查看 KPI 差异和推荐结果；需要留档时可导出 Excel。

最多可保存 5 个方案；一次对比最多选择 3 个方案。

### 导出报告

选择“报告 → 导出报告”，按需要保存为 Excel 或 PDF。暂停或停止后，可选择导出本次运行结果，保留实际时间、产出和换型记录；也可明确选择按当前配置重新试算。配置改变后，旧结果会失效。没有有效结果时，程序会先询问是否重新试算。

报告可用于方案沟通和评审，但对外使用前请确认数据来源、单位、假设条件和版本。

## 配置说明

### 产线级字段

| 字段 | 类型 | 含义 | 示例 |
| --- | --- | --- | --- |
| `name` | string | 产线名称 | `电子烟产线_标准版` |
| `shift_hours` | number | 班次时长（小时） | `8` |
| `break_minutes` | number | 休息时间（分钟） | `60` |
| `worker_hourly_wage` | number | 工人时薪（元/小时） | `20.0` |
| `stations` | array | 工序列表 | `[{...}, {...}]` |

### 工序级常用字段

| 字段 | 类型 | 含义 | 示例 |
| --- | --- | --- | --- |
| `id` | string | 工序唯一 ID | `s01` |
| `name` | string | 工序名称 | `注油` |
| `process_time` | number | 单件耗时（秒） | `25` |
| `worker_count` | integer | 工人数量 | `2` |
| `collaboration_type` | string | `parallel`（并联）或 `collaborative`（协同） | `parallel` |
| `oee` | number | 设备综合效率，范围 0–1 | `0.85` |
| `efficiency` | number | 人员效率，范围 0–1 | `0.95` |
| `changeover_time` | number | 切换停机时间（分钟） | `45` |
| `buffer_capacity` | integer | 缓冲区容量 | `100` |
| `machine_count` | integer | 机台数量，与工人数量独立 | `1` |

部分字段会随生产类型变化：

- 尼古丁袋：可配置机台节拍。
- 烟油灌装：可配置 CIP/SIP 清洗时间。
- 烟油灌装与尼古丁袋：可配置抽检比例、缺陷率和返工时长。

计量单位也会随生产类型切换：烟弹组装使用“颗”，烟油灌装使用“千克”，尼古丁袋使用“袋”。界面 KPI、方案对比和报告会同步显示对应单位。

### 成本与产量口径

- 预计日人工成本 = 工序员工及未重复统计的支持岗位人数 × 工人时薪 × 班次时长。
- 有效工时 = 班次时长 − 休息时间。
- 预计日产量按有效工时及各工序换型/清洗时间计算；本次仿真产出只统计末端合格成品。烟油按配方批次实际量、放行与罐容计算。
- 本次单位人工成本 = 同统计窗口人工费用 ÷ 合格产出；零合格产出显示为无法计算。材料成本单列，以上不代表完整制造成本。

人工工资不会扣减休息时间。可通过主界面的“班次配置”修改班次时长、休息时间和时薪。

## Excel 导入

模板位于 `e_pod_line_simulator/configs/产线配置模板.xlsx`。建议先复制模板再填写，避免修改原文件。

通过“文件 → 快速配置向导”选择 Excel 文件进行导入。导入前请检查：

- 工序 ID 不重复；
- 时间、人数、效率和容量字段使用数值；
- OEE 与人员效率位于 0–1 范围；
- 工序顺序与现场物流顺序一致；
- 所有时间和产量使用统一单位。

## 常见问题

### 如何添加新工序？

点击左侧工序配置区的“添加”，填写参数并确认。需要批量配置时，使用快速配置向导导入 Excel 模板。

### 仿真速度如何调整？

在主界面控制区选择速度倍数。速度只影响界面演示节奏，不改变仿真模型的业务口径。

### 如何模拟换型停机？

先开始仿真，再点击“停机切换（换型）”；也可以右键工序节点并选择“触发切换”。停机时长默认取该工序的切换时间，也可在对话框中修改。请求先排队，当前件加工结束后实际换型；日志区分申请、开始和结束。烟油批次换型采用配方矩阵，不使用工序按钮。

### 为什么不能编辑工序？

为避免运行中的配置和结果不一致，仿真运行时会锁定编辑、速度调整和画布拖拽。停止仿真后再修改；暂停期间仍锁定配置。

### 如何理解专业术语？

点击工序配置区域的“术语?”，或选择“帮助 → 术语说明”。“帮助 → 分析指南”还会按目标推荐相应分析工具。

### 报告为什么会先运行仿真？

报告需要当前配置对应的结果。暂停或停止后可导出本次结果；选择重新试算时会生成新的运行 ID。程序不会把重跑结果冒充先前手动操作的运行。

### 如何报告问题或提出建议？

请在 [GitHub Issues](https://github.com/MaxHou-infinity/puffline-planner/issues) 选择 Bug 或功能建议模板。提交 Bug 时请附操作系统、应用版本、复现步骤和必要的截图；不要上传企业机密或未经脱敏的生产数据。

## 数据与安全提示

- 本工具在本地运行，不需要把生产配置上传到外部服务。
- 分享配置、截图或报告前，请先移除客户名、员工信息、成本数据和其他敏感字段。
- 请仅从官方仓库和 Release 页面下载应用。
- 许可与商业使用条件以仓库根目录的 [LICENSE](../LICENSE) 为准。


## v3.4.0 的模型与数据约定

- 离散工序采用确定性班次窗口：班内先生产，班末安排休息及工序配置的换型/清洗。手动换型是额外事件。这是预评估假设，不等同于真实排班日历。
- 机台节拍能力由机台数量决定；增加机手不等于增加设备。旧 JSON/Excel 缺少机台数字段时，按旧版混用字段保留历史台数和人数；请导入后核实并保存新版配置。
- 烟油由配方与批次流程主导，暂不支持按工序人数反推烟油产能或进行人员优化；界面会明确提示。批量、投料、收率、期末罐存与待入罐量可以在报告中对账。
- 周期 CIP 与配方换型重叠时取两者较长要求，不重复扣除同一清洗；不能因启用周期清洗而缩短矩阵要求。
- HR 分别显示每班最低岗位、全天最低编制与含缺勤覆盖编制。招聘、富余和覆盖达产判断按覆盖编制及工种分别核算；没有安排到岗不假定立即招齐。
- 方案对比中的预计 KPI 与仿真实绩分别展示；敏感性与优化使用相同的仿真种子进行比较。默认桌面演示种子为 0，分析默认种子为 42。
- 方案、历史与日志保存在用户数据目录。macOS 为 `~/Library/Application Support/PuffLinePlanner/`；Windows 为 `%APPDATA%/PuffLinePlanner/`。首次使用新版时复制原 `configs/` 中的方案/历史，保留原文件；已有新文件时不覆盖。
- 可用 `PUFFLINE_DATA_DIR` 指定独立本地数据目录进行测试。保存失败会明确提示并保留原方案，不能把失败写入当作成功保存。
- 新 Excel 模板使用千克表头，兼容旧 `L` 后缀列名；该兼容仅是历史字段别名，不执行密度换算。导入前需确认数量已按当前千克口径准备。
